비전공자를 위한 6주 실전 제작 과정

바이브코딩
서비스 런칭 캠프

코딩을 몰라도 내가 만들고 싶은 서비스를 설계하고, 실제 작동하는 AI 서비스로 완성해 공개하는 과정입니다.

진행 방식온라인 6주 + 오프라인 2회
핵심 목표내 AI 서비스 1개 완성
대상비전공자·사업자·N잡러

과정 선택

165만 원 과정은 직접 제작과 완성, 225만 원 과정은 맞춤 설계와 코칭이 더해진 구조입니다.

바이브코딩 서비스 런칭 완성반

165만 원
  • 내가 만들고 싶은 서비스를 직접 설계합니다.
  • 화면, 저장, 로그인, 결제, 외부 기능 연결, 공개까지 경험합니다.
  • 6주 후 외부에 공유 가능한 서비스 링크를 완성합니다.

바이브코딩 서비스 맞춤 설계반

225만 원
  • 런칭 완성반 내용을 포함합니다.
  • 내 사업과 업무에 맞는 서비스 방향을 함께 설계합니다.
  • 오프라인 또는 맞춤 코칭 기반으로 구현을 점검합니다.
  • 20명 한정 모집
선착순 결제 30명은 원데이 해커톤 참여 가능. 세부 운영 방식은 추후 확정 가능합니다.

커리큘럼 한눈에 보기

PRD, 프론트, DB, API 같은 어려운 개발 용어 대신 초보자가 바로 이해할 수 있는 표현으로 구성했습니다.
